# Generative AI Declaration

The assessment uses GenAI Level 2. Paste **one** of the two statements below
into the submission comments box on Blackboard, keeping only the statement that
applies to your own work.

## Statement A - GenAI was used

> I used generative AI in this assessment at Level 2. I used [tool name, e.g.
> an AI coding assistant] for the following purposes: [e.g. discussing class
> design options, explaining compiler errors, checking the wording of
> documentation comments]. I did not use it to generate the submitted source
> code, and I did not use it to write the video presentation. I can explain
> every part of the submitted code and the reasoning behind it.

## Statement B - GenAI was not used

> I did not use generative AI in this assessment. All design decisions, source
> code, comments and the presentation video are my own work. I can explain
> every part of the submitted code and the reasoning behind it.

## Notes

- The brief forbids AI-generated code, AI-written comments and AI-produced
  presentation videos. Reading and understanding existing material, including
  the code in this repository, does not by itself remove the obligation to be
  able to explain it.
- You may be invited to a short interview about the code. If you cannot explain
  the code you submitted, the university may treat it as a breach of academic
  integrity, so make sure you read through the classes until each design choice
  is yours to justify.
